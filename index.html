⚙️ Lab Execution & Automated Tooling Suite

The practice lab and all verification test suites can be executed with zero external dependencies using native Node.js:

# 1. Start the authorized vulnerable training lab:
npm start
# (Runs on http://127.0.0.1:3000 in VULNERABLE_TRAINING mode)

# 2. Generate a clean baseline cryptographic snapshot:
npm run baseline

# 3. Execute local reconnaissance & attack surface mapping:
npm run recon

# 4. Execute non-destructive OWASP vulnerability verification:
npm run test:owasp

# 5. Execute automated retest verification against secured instance:
npm run retest

Reviewers can also start the application directly in remediated mode using npm run start:secure.
